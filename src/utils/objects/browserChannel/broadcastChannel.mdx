        # BrowserChannel Class
        Typed wrapper around the browser `BroadcastChannel` API. It supports:
        - a typed `post` method for sending messages to every other same-origin context on the channel
        - a single `onMessageCallback` for incoming messages, already unwrapped from the raw `MessageEvent`
        - a separate `onErrorCallback` for `messageerror` events (payloads that failed to deserialize)
        - `close()` to tear down the channel and remove its listeners in one call

        ## Import
        <RenderSource>
```
import { BrowserChannel } from '@apple-pie/slice/utils/objects';
```
</RenderSource>

        ## Basic usage
        <RenderSource>
```
type ChatMessage = {
	id: string;
	text: string;
};

const channel = new BrowserChannel<ChatMessage>({
	name: 'chat',
	onMessageCallback: (message) => {
		console.log(message.text);
	},
	onErrorCallback: (event) => {
		console.error('failed to deserialize message', event);
	},
});

// sent to every other same-origin tab/window/worker listening on 'chat'
channel.post({ id: '1', text: 'hello' });
```
</RenderSource>

        ## Same-origin only
        `BroadcastChannel` only delivers messages between browsing contexts on the same origin (scheme, host, and port). Use it for cross-tab or cross-worker communication within your app, not for cross-origin messaging — for that, look at `window.postMessage` instead.

        ## Unsupported environments
        `BrowserChannel` throws a `TypeError` at construction time if `BroadcastChannel` is not available, such as during server-side rendering or in older browsers:

        <RenderSource>
```
// throws: "BroadcastChannel is not supported in this environment."
new BrowserChannel({
	name: 'chat',
	onMessageCallback: () => {},
	onErrorCallback: () => {},
});
```
</RenderSource>

        Guard construction with a feature check if you need to run in an environment where `BroadcastChannel` may be unavailable:
        <RenderSource>
```
if (typeof BroadcastChannel !== 'undefined') {
	const channel = new BrowserChannel({
		name: 'chat',
		onMessageCallback: (message) => console.log(message),
		onErrorCallback: (event) => console.error(event),
	});
}
```
</RenderSource>

        ## Cleanup
        Always call `close()` when you are done with the channel. This closes the underlying `BroadcastChannel` and removes its listeners.

        <RenderSource>
```
const channel = new BrowserChannel({
	name: 'chat',
	onMessageCallback: (message) => console.log(message),
	onErrorCallback: (event) => console.error(event),
});

// later
channel.close();
```
