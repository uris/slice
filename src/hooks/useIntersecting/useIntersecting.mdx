        # useIntersecting
        Tracks intersection of one or more elements — by ref or CSS selector — against a container using `IntersectionObserver`, returning the latest intersection state for every resolved target, plus enter/exit transitions and on/off-screen partitions. Commonly used for infinite scroll sentinels, lazy loading, and view/impression tracking.

        Elements are (re)resolved — refs read, string selectors passed to `document.querySelectorAll` — whenever `options.entries`, `options.thresholds`, `options.margin`, or `options.container` actually change, not on every render. A single `IntersectionObserver` is created per resolution and disconnected on cleanup.

        ## Signature
        `useIntersecting(options?)`

        ## Code Examples
        </Unstyled>

        <RenderSource language={"tsx"}>
        ```
        import { useEffect, useRef } from 'react';
        import { defaultOptions, useIntersecting } from '@apple-pie/slice';

        function InfiniteList() {
            const containerRef = useRef<HTMLDivElement>(null);
            const sentinelRef = useRef<HTMLDivElement>(null);

            const { onScreen } = useIntersecting({
                ...defaultOptions,
                container: containerRef,
                entries: sentinelRef,
                thresholds: 0.1,
                margin: 200,
            });
            const sentinelVisible = onScreen.length > 0;

            useEffect(() => {
                if (sentinelVisible) loadNextPage();
            }, [sentinelVisible]);

            return (
                <div ref={containerRef} style={{ overflowY: 'auto', height: 320 }}>
                    {items.map((item) => <Row key={item.id} item={item} />)}
                    <div ref={sentinelRef} />
                </div>
            );
        }
        ```
        </RenderSource>

        <Unstyled>
        Observing a list of items by class selector works the same way — read `dataset` (or any DOM attribute) off `target` to identify which item changed:
        </Unstyled>

        <RenderSource language={"tsx"}>
        ```
        const { entered, exited } = useIntersecting({
            ...defaultOptions,
            container: containerRef,
            entries: '.list-item',
            thresholds: 0.5,
        });

        const enteredIds = entered.map((result) => result.target.dataset.itemId);
        const exitedIds = exited.map((result) => result.target.dataset.itemId);
        ```
