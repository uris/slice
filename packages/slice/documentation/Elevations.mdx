            # Elevations
            Elevation tokens are named `z-index` layers. Instead of picking arbitrary numbers, choose the level that matches what the element is - a toast sits at `status`, a tooltip at `describe` - and stacking stays predictable across components. Each level is exposed as a CSS custom property (`--elevation-*`) and as a value on the `elevations` token object.

            #### Levels
            <StyleTokenTable tokens={elevationTokens} columnDefinitions={elevationColumnDefinitions} />

            #### Stacking Order
            Each card below uses its own elevation token as its `z-index`. The higher the level, the closer to the front.
            <ElevationStack />

            #### Notes
            - Levels are spaced `100` apart, leaving room to slot in a custom level between two tokens if you ever need one.
            - Elevation only orders elements within the same stacking context. If a positioned ancestor creates its own context, a token inside it cannot escape above elements outside of it.
