        # Utility Functions
        Small browser and styling helpers exported from `@apple-pie/slice/utils`.

        ## Import
        <RenderSource language={"tsx"}>
        ```
        import {
            addOpacity,
            copyToClipboard,
            debounce,
            hexToRgb,
            resolveColor,
            tintFromColor,
        } from '@apple-pie/slice/utils';
        ```
        </RenderSource>

        ## Theme color tokens

        Component color props accept `ColorValue`: a `keyof Colors` token with autocomplete,
        or any CSS color string. For example, `background="core-surface-primary"` and
        `textColor="core-text-primary"` resolve to CSS variables and follow the active theme.
        Hex colors, named colors, `var(...)`, and existing semantic Label backgrounds still work.
        Numeric icon fill opacity is unchanged. Raw React `style` objects use normal CSS values;
        call `resolveColor()` yourself when passing a token through `style`.

        <RenderSource language={"tsx"}>
        ```
        import { Button, FlexDiv, type ColorValue } from '@apple-pie/slice';
        import { resolveColor } from '@apple-pie/slice/utils';

        const color: ColorValue = 'core-text-primary';
        const cssColor = resolveColor(color); // 'var(--core-text-primary)'
        const customColor = resolveColor('#ff00aa'); // '#ff00aa'

        <FlexDiv background="core-surface-primary">
            <Button label="Continue" textColor={color} iconColor="core-icon-primary" />
            <span style={{ color: cssColor }}>Themed text</span>
        </FlexDiv>
        ```
        </RenderSource>

        ## General Utils.

        ### `copyToClipboard`
        Copies a string into the system clipboard and resolves to `true` when the operation succeeds.

        <RenderSource language={'tsx'}>
        ```
        async function handleCopy() {
            const ok = await copyToClipboard('Hello world');
            console.log(ok);
        }
        ```
        </RenderSource>

        ### `debounce`
        Delays a function call until input has stopped for the configured time. The returned function also supports `cancel()` and `flush()`.

        <RenderSource language={'tsx'}>
        ```
        const saveDraft = debounce((value: string) => {
            console.log('saving', value);
        }, 250);
        
        saveDraft('first');
        saveDraft('second');
        
        saveDraft.cancel();
        
        saveDraft('third');
        saveDraft.flush();
        ```
        </RenderSource>

        ## Color Utils.
        Helpers for converting or adjusting color values.

        ### `hexToRgb`
        Converts a hex color string into an RGB string literal.

        <RenderSource language={'tsx'}>
        ```
        const color = hexToRgb('#336699');
        // "rgb(51, 102, 153)"
        ```
        </RenderSource>

        ### `tintFromColor`
        Lightens or darkens a hex color by mixing it toward white or black.

        <RenderSource language={'tsx'}>
        ```
        const lighter = tintFromColor('#336699', 20);
        const darker = tintFromColor('#336699', -20);
        ```
        </RenderSource>

        ### `addOpacity`
        Applies an alpha value to a hex or RGB color and returns an `rgba(...)` string.

        <RenderSource language={'tsx'}>
        ```
        const overlay = addOpacity('#336699', 0.5);
        const muted = addOpacity('rgb(51, 102, 153)', 0.2);
        ```
        </RenderSource>
