        # ActiveTabStore
        Global document visibility and focus state built with Zustand. It mirrors `useActiveTab` while exposing atomic selector hooks for React and imperative reads for non-React code.

        ## Initialization
        Call `initialize()` in an app-level effect and return its cleanup. Multiple initializers share one set of visibility, focus, and blur listeners; the final cleanup removes them. Cleanup is safe to call more than once. Reinitializing synchronizes immediately, and the store retains its last state after cleanup.

        ## SSR behavior
        The store is safe to import during SSR. State defaults to `isActiveTab: false`, `isTabFocused: false`, and `visibilityState: 'hidden'` until initialized in the browser. Without a document, initialization returns a no-op cleanup. Importing the store does not attach browser listeners.

        ## React exports (reactive)
        React exports are reactive subscriptions for components that should re-render when the selected state changes.

        ## Notes
        Active means visible; focus is tracked separately. Combine `isActiveTab` and `isTabFocused` when both are required. Full window occlusion may be reported as hidden depending on browser/OS support and is not a reliable measure of window coverage or user attention.

        ## Example from `useActiveTab` to `ActiveTabStore`
        Initialize at the app level, then read the same values through atomic selectors anywhere in the app.
        </Unstyled>
        <RenderSource language={"tsx"}>
        ```
        import { useEffect } from 'react';
        import { useInitializeActiveTab, useIsActiveTab, useIsTabFocused, useTabVisibilityState } from '@apple-pie/slice/stores/activeTab';

        function App() {
            const initialize = useInitializeActiveTab();
            useEffect(() => initialize(), [initialize]);
            const active = useIsActiveTab();
            const focused = useIsTabFocused();
            const visibility = useTabVisibilityState();
            return (
                <div>
                    <span>Visibility: {visibility}</span>
                    <br />
                    <span>Focused: {String(focused)}</span>
                    <br />
                    <span>Visible and focused: {String(active && focused)}</span>
                </div>
            );
        }
        ```

        ## Imperative usage outside React

        `isActiveTab()`, `isTabFocused()`, and `tabVisibilityState()` read the latest values without subscribing. Subscribe to the store for
        changes; unsubscribe when finished. If the app already initializes the store, only the
        subscription is needed here. Importing the store does not attach browser listeners.
        </Unstyled>
        <RenderSource language={"ts"}>
        ```
        import { activeTabActions, isActiveTab, useActiveTabStore } from '@apple-pie/slice/stores/activeTab';

        const dispose = activeTabActions.initialize();
        console.log(isActiveTab());
        const unsubscribe = useActiveTabStore.subscribe((state, previous) => {
            if (state.isActiveTab !== previous.isActiveTab || state.isTabFocused !== previous.isTabFocused) {
                console.log('Active:', state.isActiveTab, 'Focused:', state.isTabFocused);
            }
        });

        // When this consumer is finished:
        unsubscribe();
        dispose();
        ```
