# CheckBox

Choose an option or show a partially selected group. Use label for text and its
accessible name; label takes precedence over children. Omit label for custom content.

## Behavior

The checkbox keeps local state and synchronizes when checked changes. Activating a
mixed checkbox checks it. onChange always reports a boolean. The div root does not
submit a native form value or provide required-field validation.

Long labels wrap within the available width; line breaks are preserved. Use
`align="top"` or `align="bottom"` to align the icon with the text block. The default
is middle. Constrain width when needed, for example with style maxWidth. Use
textTopOffset for a manual correction: positive moves text down, negative moves it up.

## Accessibility

The root has role=checkbox, aria-checked, and aria-disabled. Enter and Space toggle
it, with a visible keyboard focus indicator. Disabled controls leave the tab order.
The accessible name comes from label or the rendered children. aria-label and
aria-labelledby can override it; provide one for controls without visible text.
Icons are decorative and do not add tab stops.

## Props

All props are optional. Color props accept Slice theme tokens or CSS colors.
Explicit color overrides also apply while disabled.

## Events

onChange: `(state: boolean) => void`. Reports user toggles, not prop updates.
Disabled controls do not emit it.

Standard native div events pass through. onClick and onKeyDown run before the
internal toggle; call event.preventDefault() to cancel it. There are no special
Motion events.
