        # Icon
        Renders icons from the shared icon registry with configurable size, stroke, and interaction states.

        ## Base element
        `SVGSVGElement`

        ## Interface
        `IconProps`

        Static icons accept `iconName`; clickable icons accept `actionName` and use button semantics.
        Use `decorative` for redundant static artwork. Enter and Space activate clickable icons with real click events.
        Color transitions respect reduced motion.

        ## Notes
        - Icon names come from the shared slice registry and are passed through the <code>name</code> prop.
        - Recent media control additions include <code>'play'</code>, <code>'play circle'</code>, <code>'pause'</code>, <code>'pause circle'</code>, and <code>'fullscreen'</code>.
