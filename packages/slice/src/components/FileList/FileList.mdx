# FileList

Controlled attachments with file icons, upload progress, errors, and removal.

```
import { FileList, type FileItem } from '@apple-pie/slice';
import { useState } from 'react';

export function Attachments() {
  const [files, setFiles] = useState<FileItem[]>([
    {id: 'report', file: 'report.pdf'},
    {id: 'notes', file: 'notes.md'},
  ]);
  return <FileList files={files} onChange={setFiles} />;
}
```

## Attachment cards

Use `variant="attachments"` to render the same files as thumbnail cards. The default
`variant="list"` keeps compact file rows. Both variants accept the same `FileItem[]`
and controlled `onChange` callback, preserve stable item identity, and move keyboard
focus to the next removal button after removal (or the list when empty).

```
<FileList
    variant="attachments"
    attachmentSize="s"
    files={files}
    onChange={setFiles}
/>
```

Cards display image previews or text excerpts when `file` is a browser `File`, and file-type
icons otherwise. Uploading cards replace metadata with a spinner and percentage; removal
is hidden while uploading, matching compact rows. Upload errors appear as alerts inside the preview, keeping card dimensions stable. Failed cards remain removable even if their upload flag is still true.

`attachmentSize` uses Attachment's named card sizes. `direction`, `gap`, `textSize`,
`iconSize`, `padding`, `backgroundColor`, and width constraints also apply to cards.
A column stacks cards at their natural size rather than stretching them across the list.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| variant | list or attachments | list | Choose compact rows or thumbnail cards. |
| attachmentSize | xs, s, m, l, or xl | s | Attachment card width and preview height. |
| backgroundColor | ColorValue | core-surface-secondary | Compact progress fill or attachment card background. |
| canRemove | boolean | true | Show removal buttons for items that are not uploading. |
| direction | row or column | row | Wrapping row or stacked column; compact column rows fill the list width. |
| files | FileItem[] | [] | Controlled attachments; see below. |
| gap | number | 10 | Space between items in pixels. |
| iconSize | number | 24 in list, 48 in attachments | File icon size in pixels. |
| listName | string | Files | Accessible name for the list. |
| maxWidth | number or string | undefined | Maximum item width; compact column mode uses 100%. |
| minWidth | number or string | undefined | Minimum item width; compact columns default to 100%. Zero is respected. |
| padding | number or string | 6px in list, 0 4px in attachments | Compact row padding or card information-row padding; overrides are exact. |
| textSize | xs, s, m, l, or xl | s | Filename text size. |
| ...divAttributes | HTMLAttributes | — | Native attributes, styles, class names, and events apply to the wrapper. Children are not rendered. |

A `FileItem` has `id?: string`, `file: File | string`, `uploading?: boolean`, `progress?: number`, and `error?: string`. Supply a unique ID when recreating attachment objects; retained item objects or File objects have stable fallback identity. Duplicate filenames are supported.

Progress uses **0–100 percent only**: 1 means 1%. Values are rounded and clamped. Missing or nonfinite progress is indeterminate while uploading and defaults to 100% otherwise. Uploading hides removal; failed cards restore removal and replace the preview with an alert. Compact rows show an alert beside the filename with a warning border. File icons use the shared extension resolver.

## Events

- `onChange?: (files: FileItem[]) => void`: remaining attachments after removal. Pass a state setter directly; FileList does not mutate its own files.
- `onToolTip?: (tip: ToolTip | null) => void`: filename-specific remove tooltip on hover/focus. Clears when neither applies, on removal, or on trigger unmount.
- Native DOM events apply to the wrapper. A forwarded ref targets its HTMLDivElement.

## Accessibility

The wrapper and items have list semantics. Progress bars have task-specific names and numeric values when known; spinners and file icons are decorative. Errors are announced without duplicating spinner announcements. Native removal buttons support Enter and Space and show keyboard-only focus outlines. Removal focuses the next action, previous action, or empty list. Reduced motion disables progress transitions and spinner motion.

`FileItem[]` composes with UploadArea.files and PromptInput.attachments. UploadArea.onFilesChange and PromptInput.onAttachmentsChange accept the same array setter as FileList.onChange.
