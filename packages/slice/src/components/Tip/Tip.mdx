# Tip

Slice components handle tooltip activation and cleanup for you. Button,
IconButton, ToggleButton, and Chip handle hover and focus and supply the hint
label and source-element ref through `onToolTip`. The shared Tip handles
positioning, timing, and dismissal.

Add a `tooltip` label and pass `onToolTip` directly to the shared tip store:

```tsx
import { Button } from '@apple-pie/slice';
import { tipActions } from '@apple-pie/slice/stores/tip';

<Button label="Project details" tooltip="Your changes are saved automatically."
  onToolTip={tipActions.push} />;
```

Mount this once in your app shell:

```tsx
import { useRef } from 'react';
import { Tip, useToolTip } from '@apple-pie/slice';
import { useTip } from '@apple-pie/slice/stores/tip';

function ApplicationTip() {
  const tip = useTip();
  const ref = useRef<HTMLDivElement>(null);
  const coords = useToolTip(tip, ref);
  return <Tip ref={ref} tip={tip} coords={coords} />;
}
```

## Custom components

Expose `onToolTip?: (tip: ToolTip | null) => void`. On hover or focus, send
`{ ref, payload: { label: 'Your hint' } }` using a ref to your source element.
Send `null` on click, or when both hover and focus have ended. Consumers can pass
`tipActions.push` directly, using the same shared Tip and positioning hook.

## Behavior

The wrapper stays mounted while hidden so it can be measured. A nonempty label and finite coordinates (including zero) schedule a request after
`showDelay` (500ms). The default reveal is 150ms with Water easing. Hiding is
instant. A new request replaces timers; changing coordinates does not restart them.
`hideDelay` defaults to 2500ms from reveal; `tip.payload.duration` overrides it.
Expiry applies even while a trigger remains active. Clearing data or coordinates,
clicks, and Escape cancel pending/visible tips. Unmount clears timers/listeners.

`useToolTip` measures the mounted wrapper, centers below the anchor, flips above
when needed, and clamps both axes to the viewport. It tracks geometry while a
request exists, including scrolling, resizing, and layout/transform movement.
Missing/removed anchors return undefined coordinates. Equal geometry keeps the
same coordinate object and does not trigger rendering.

## Props

| Prop | Type | Default |
| --- | --- | --- |
| backgroundColor | ColorValue | core-surface-secondary |
| border | boolean | true |
| borderColor | ColorValue | core-outline-primary |
| borderRadius | number or string | corner-xs (4px) |
| coords | finite x/y numbers | undefined |
| hideDelay | number, milliseconds | 2500 |
| padding | number or string | 4px 8px |
| showDelay | number, milliseconds | 500 |
| textColor | ColorValue | core-text-primary |
| textSize | xs, s, m, l, xl | s |
| tip | ToolTip or null | undefined |

Use `textColor` and `borderRadius`; legacy `color` and `radius` are removed.
Native div attributes/events are forwarded, classes appended, and styles merged.
Content, ARIA semantics, and animation are managed internally. Native color,
drag, and animation-start handlers are excluded. The ref targets the mounted div.

## Motion

`motionValues?: Variants` overrides initial/animate states. Each reveal resets the
initial state. `transition?: Transition` customizes reveal only; removal never
waits for animation. Reduced motion is observed live and cancels custom movement,
fading, and animation delays while retaining the show delay and lifetime.

## Accessibility

The wrapper has `role="tooltip"` and is hidden while inactive. Visible tips add
their ID to the trigger's `aria-describedby` through `tip.ref`, preserving existing
descriptions and removing only their own association when hidden. Escape dismisses
without moving focus. Controls must activate on hover and focus, and clear requests
on leave/blur/click. Tips are descriptive text, without pointer input or focusable
content. Use a dialog or menu for interactive content.
