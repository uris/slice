        # AudioLevel
        Renders a horizontal audio level meter driven by the `AudioVisualizer` utility.
        It maps normalized microphone or stream intensity into a row of bars, then lights up bars from left to right as the signal gets stronger.

        ## Accessibility
        Decorative by default. Set `levelName` to expose a named meter whose value is the number of lit bars.
        Updates are not live announcements. Discrete audio feedback remains visible with reduced motion; decorative CSS transitions are disabled.

        ## Behavior
        - `barCount` controls the total number of bars.
        - `minActiveBars` controls the resting number of active bars.
        - Live audio intensity is normalized to `0..1`, then mapped into an active bar count between `minActiveBars` and `barCount`.

        Pausing resets to `minActiveBars` and suspends analysis; it does not stop the input tracks.
        Missing or ended audio and startup failures leave the meter at rest. Replacing the source releases the old analyser.
        Positive finite sensitivity, peak, and response settings are required; invalid values use analyser defaults.

            gap={4}
            barCount={8}
            minActiveBars={0}
            backgroundColorActive="var(--feedback-positive)"

        />
    );
}
