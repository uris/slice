# RadioButtonList

Compose related choices for one selection. Use CheckBox for multiple selection.

## Usage

</Unstyled>
<RenderSource>
```
import { RadioButton, RadioButtonList } from '@apple-pie/slice';

<RadioButtonList label="Billing" defaultValue="monthly">
  <RadioButton value="monthly" label="Monthly" />
  <RadioButton value="annual" label="Annual" />
</RadioButtonList>
```

## Composition and selection

value/onChange controls one selection; defaultValue initializes local selection.
Each grouped RadioButton needs a unique, non-null value. Values identify choices,
so selection survives reordering. Children can appear inside wrappers or custom
components. Children take priority over options; the array is shorthand over the
same group context. Group styles are defaults; explicit child styles override them.
The group owns selection, shared name, and disabled state. A disabled child remains
disabled, and disabled=false cannot override a disabled group.

## Forms

Set name for native form submission. Child formValue serializes object-valued
choices when needed. Uncontrolled groups reset to their initial defaultValue;
controlled forms should reset application state. Reset does not emit onChange.

## Accessibility

label names the radiogroup, or use aria-label without a visible heading. Each
radio's label names and activates it; icons are decorative. Tab enters the group,
Space selects, and arrows select enabled choices. Focus is visible. Native input
props such as required belong on child radios. Reduced motion disables color
transitions while selection remains immediate.

## Props

All group props are optional. Each choice needs a value. Colors accept theme tokens
or CSS colors. Option styles below provide defaults for child radios.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `align` | `'top' \| 'middle' \| 'bottom'` | `middle` | Aligns the icon with the content. Use top for a multiline label. |
| `backgroundColor` | `ColorValue` | `transparent` | Unselected background. |
| `backgroundColorSelected` | `ColorValue` | `transparent` | Checked background. |
| `borderColor` | `ColorValue` | `core-outline-primary` | Border color. |
| `borderRadius` | `number \| string` | `8` | Corner radius; numbers are pixels. |
| `borderWidth` | `number` | `0` | Border width in pixels. Negative or nonfinite numbers become zero. |
| `children` | `React.ReactNode` | `undefined` | Composed RadioButton choices, optionally inside wrappers or custom components. Each grouped radio needs a unique, non-null value. Children take priority over options when supplied. |
| `defaultValue` | `T \| null` | `null` | Initial local selection. Later changes do not reset it. Use value for external control. |
| `direction` | `'row' \| 'column'` | `column` | Layout direction, independent of borders or frames. |
| `disabled` | `boolean` | `false` | Disables all descendant choices. A child cannot override a disabled group. |
| `gap` | `number` | `16` | Pixel spacing between direct group children and the optional heading. Custom layout wrappers control spacing inside themselves. |
| `iconChecked` | `string` | `check circle` | Icon while checked. |
| `iconColor` | `ColorValue` | `core-text-primary` | Unselected icon color. |
| `iconColorSelected` | `ColorValue` | `undefined (iconColor)` | Checked icon color. Falls back to iconColor. |
| `iconSize` | `number` | `20` | Icon size in pixels. Zero removes the icon and its gap. Negative or nonfinite values fall back to 20px. |
| `iconUnChecked` | `string` | `circle` | Icon while unchecked. |
| `itemGap` | `number` | `6` | Default pixel gap between each radio’s icon and text. A child gap prop overrides it. |
| `label` | `string` | `undefined` | Visible heading and accessible group name. |
| `marginBottom` | `number \| string` | `0` | Space below the group. Numbers are pixels; strings accept CSS lengths. |
| `name` | `string` | `generated unique name` | Shared native radio group and form field name. The group supplies it to every descendant radio. Use distinct names for independent groups. |
| `options` | `RadioButtonListOption<T>[]` | `[]` | Data shorthand for composed choices. Each option accepts RadioButton props with a required value, excluding checked, defaultChecked, and name. Rendered through the same group context as explicit children. |
| `padding` | `number \| string` | `0` | Uniform surface padding. Numbers are pixels; strings accept CSS shorthand. |
| `textColor` | `ColorValue` | `core-text-primary` | Content color. |
| `textSize` | `'xs' \| 's' \| 'm' \| 'l' \| 'xl'` | `m` | Content size. |
| `textTopOffset` | `number` | `0` | Manual content alignment in pixels. Positive values add top padding; negative values add bottom padding to raise the text. Does not move the icon. |
| `value` | `T \| null` | `undefined` | Controlled selection; null clears it. Choices match using Object.is. Prefer unique primitive values; keep object references stable. A value without a matching choice leaves no input checked. |
| `width` | `number \| string` | `min-content` | Group width; numbers are pixels and strings accept CSS dimensions. |
| `wrap` | `boolean` | `false` | Allows direct children to wrap. Most useful with direction=row and a constrained width. |
| `...divAttributes` | `React.HTMLAttributes<HTMLDivElement>` | `undefined` | Other native attributes apply to the outer group. className is appended and style is merged; component CSS variables take priority over overlapping variable fields. The role stays radiogroup. |

## Events

- **onChange**: `(value: T, option: RadioButtonOption<T>) => void`. Requests a newly selected value. The second argument contains fieldName, label, and value metadata. Runs after the child’s onChange. Repeat activation, prop changes, and form reset do not emit another change.
- **...divEvents**: `React.DOMAttributes<HTMLDivElement>`. Other native handlers apply to the outer group. Keyboard selection remains native to the radio inputs; there are no drag or animation lifecycle callbacks.
