        # ModalController
        Renders the active global modal from `ModalStore` and places an overlay beneath it.

        Mount one `ModalController` near the app root when using the modal store. The controller owns overlay rendering, enter and exit animation, and optional dragging.

        ## Replacement and dismissal

The store holds one modal without stacking. Every new stored instance gets fresh
presentation/drag state, including when IDs are reused or omitted. Exiting panels
are inert and stop trapping focus or handling Escape. A replacement receives its
own initial focus; dismissal restores the opener and background/scroll state.

Callbacks are bound to their exact instance. Retained callbacks from replaced or
closed dialogs cannot affect a newer modal. Store settlement precedes descriptor
callbacks, so a throwing consumer callback cannot strand a pending modal.

Always catch `modalResponse()` rejection: close, backdrop, Escape, clear, and
replacement reject a pending response. `show()` is fire-and-forget.

Reduced motion overrides custom animation delays and movement, including live
changes during entry/exit. Use `motionValues={{ initial, animate, exit }}` and
`transition` for custom motion, matching PopMenu. Partial states merge with defaults. Manual dragging stays enabled
when `draggable` is true; close/action controls do not initiate it.

        ## Behavior
        `ModalController` reads the current modal from the modal store and injects `onResolve`, `onReject`, `onClose`, and `onDragPointerDown` into the rendered modal component.

        ## Code Examples
        </Unstyled>

        <RenderSource language={"tsx"}>
```
import { useRef } from 'react';
import { Button, FlexDiv, DialogBox, ModalController } from '@apple-pie/slice';
import { useModalActions } from '@apple-pie/slice/stores/modal';

export function ModalControllerExample() {
    const actions = useModalActions();
    const boundsRef = useRef<HTMLDivElement>(null);

    return (
        <FlexDiv ref={boundsRef} height={320} justify="center" align="center">
            <Button
                onClick={() =>
                    actions.show({
                        component: DialogBox,
                        props: {
                            title: 'Confirmation',
                            children: 'Continue?',
                        },
                    })
                }
            >
                Open DialogBox
            </Button>
            <ModalController dragConstraintsRef={boundsRef} />
        </FlexDiv>
    );
}
```

## Modal hosting

Use `DialogBox` for the named dialog panel. `ModalController` supplies modal state, initial focus, focus containment and restoration, Escape dismissal, background inertness, and page scroll locking. It restores background state when the active panel is dismissed. The controller settles the store before descriptor callbacks run.
