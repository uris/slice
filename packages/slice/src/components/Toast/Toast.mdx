# Toast

Brief status notifications with optional automatic dismissal. Render one instance
for an application shell, or a contained instance with `container="parent"` inside
a positioned parent. The optional toast store holds one notification, without a queue.

## Identity and timing

A new `message` or `notificationId` starts a notification after `showDelay`.
Changing the ID replays identical text without a React key. Empty text or `null`
clears it. Hover and focus pause the remaining duration; both must end to resume.
Changing `duration` restarts its lifetime while respecting an active pause.
Changing `showDelay` only reschedules a pending show.

## Props

| Prop | Type | Default | Purpose |
| --- | --- | --- | --- |
| border | boolean | true | Notification border. |
| borderRadius | number or string | corner-m (8px) | Corner radius. |
| close | boolean | true | Native dismiss button, independent of duration. |
| closeLabel | string | Dismiss notification | Accessible button label; empty uses the default. |
| container | window or parent | window | Fixed viewport or absolute parent positioning. |
| data | T | undefined | Application payload passed to onClick. |
| duration | number or 'infinite' | 5000 | Visible lifetime in milliseconds. |
| message | string or null | null | Notification text. |
| notificationId | string | undefined | Replay identity. |
| offset | number | 24 | Edge inset and minimum horizontal clearance in pixels. |
| padding | number or string | 8px 16px; close edge 12px | Inner spacing; zero is respected. |
| position | top or bottom | bottom | Placement edge and motion direction. |
| progress | boolean | false | Working indicator, independent of duration. |
| showDelay | number | 0 | Delay before showing, in milliseconds. |
| textSize | xs, s, m, l, xl | m | Body text size. |
| type | ToastType or matching string | info | info, success, warning, error treatment. |
| urgency | polite or assertive | polite | Live announcement priority. |

Native div attributes are forwarded to the visible wrapper; class names are
appended and styles merged. Content, ARIA semantics and animation are managed
internally. Native drag and animation-start handlers are excluded. The forwarded
ref targets the visible div. Long messages wrap inside the available width.

## Motion

`motionValues?: Variants` merges `initial`, `animate`, and `exit` states.
`transition?: Transition` overrides the Water theme transition. Defaults fade and
move 8px from the selected edge. Live reduced-motion preferences override custom
motion and delays, and replace the spinning indicator with a static one.

## Events

`Toast<T>` and `ToastProps<T>` infer the payload type from `data`.
`onClick(event: React.MouseEvent<HTMLDivElement>, data: T | undefined)` receives
that payload on pointer activation or Enter/Space. A native action button uses the
message as its accessible name, separate from the dismiss button. Dismissal never
triggers the action. Clicking does not dismiss automatically. Data is undefined
when omitted. The shared store accepts typed payloads and handlers directly.

```tsx
<Toast message="Open saved document" data={{ documentId: 'doc-42' }}
  onClick={(_event, data) => {
    if (data) window.location.assign('/documents/' + data.documentId);
  }} />
```

`onShow(info: ToastInfo)` runs once when shown after the delay. Its payload contains
`notificationId` and `message`. `onHide(info: ToastHideInfo)` runs once after exit
and adds `reason`: timeout, dismiss, cleared, or replaced. Notifications retain
their original callback and identity across replacement. Unmount cancels timers
without a hide callback. Native hover/focus callbacks run alongside timer handling.

## Accessibility

A persistent live region announces updates. Use `urgency="assertive"` for urgent
alerts. Notifications do not take focus automatically. The native close button
supports Enter and Space, shows keyboard focus, and restores prior focus when
dismissing from inside the notification. Timers pause during hover or focus.

## Migration

Use `borderRadius`, `notificationId`, `onHide`, and lowercase `'infinite'` in place
of `radius`, `notifId`, `didHide`, and `'Infinite'`. Persistence no longer forces
progress or a close button; set those props explicitly.
