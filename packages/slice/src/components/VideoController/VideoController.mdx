        # VideoController
        Renders the active global video from `VideoStore` and places an overlay beneath it.

        Mount one `VideoController` near the app root when using the video store. The controller owns overlay rendering, enter and exit animation, optional dragging, keyboard focus containment, and dismissal while media is loading.

        ## Base element
        `HTMLDivElement`

        ## Interface

        ## Behavior
        `VideoController` reads the current video descriptor from the video store and renders its `component` with the provided `props`.

        Controller-owned props include:
        - `borderRadius`, when explicitly supplied
        - `showProgressIndicator`, which defaults to `true` and overrides the active video's setting
        - `onLoadedFrameData`, which tracks readiness and also forwards to the descriptor callback

        Loading, error feedback, and dismissal remain available before the first frame. Set `showProgressIndicator={false}` on the controller to disable the spinner. Each replacement descriptor owns a fresh player lifecycle, even when its optional ID is omitted or reused. Exiting players pause immediately.

        To receive readiness notifications, pass `onCanPlay` in the video descriptor's `props`. The controller forwards it to the video component.

        `customControls` overrides descriptor control options, which override Video's defaults. `quit` defaults to `inside`; `outside` places a close button beside the player, and `none` omits the close button. A fallback close button remains available while loading or when the chosen player controls cannot show an inside close button.

        `dialogName` names the modal and defaults to “Video player”. The controller contains keyboard focus, locks background interaction and scrolling, handles Escape, and restores the opener on dismissal. Backdrop, Escape, and close-button dismissal call both the descriptor's and controller's `onQuit` callbacks once. A store clear or replacement does not emit those callbacks.

        ## Code Examples
        </Unstyled>

        <RenderSource language={"tsx"}>
```
import { Button, FlexBox, Video, VideoController } from '@apple-pie/slice';
import { useVideoActions } from '@apple-pie/slice/stores/video';

export function VideoControllerExample() {
    const actions = useVideoActions();

    return (
        <FlexBox justify="center" align="center" height={320}>
            <Button
                onClick={() =>
                    actions.show({
                        component: Video,
                        props: {
                            src: 'https://example.com/video.mp4',
                            controls: 'simple',
                            muted: false,
                            width: '100%',
                            height: 'auto',
                            onCanPlay: () => console.log('Ready to play'),
                        },
                    })
                }
            >
                Open Video
            </Button>
            <VideoController showProgressIndicator={false} />
        </FlexBox>
    );
}
```

        ## Drag Constraints
        Use `dragConstraintsRef` when the active video should stay within another element's bounds.
        </Unstyled>

        <RenderSource language={"tsx"}>
```
import { useRef } from 'react';
import { FlexBox, VideoController } from '@apple-pie/slice';

export function ConstrainedVideoControllerExample() {
    const ref = useRef<HTMLDivElement>(null);

    return (
        <FlexBox ref={ref} height={360} justify="center" align="center">
            <VideoController dragConstraintsRef={ref} />
        </FlexBox>
    );
}
```
