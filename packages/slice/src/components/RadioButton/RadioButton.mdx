# RadioButton

Choose one option with a selection icon and a label. Styling and multiline alignment
follow CheckBox; selection and form behavior use a native radio input.

## Usage

</Unstyled>
<RenderSource>
```
import { RadioButton } from '@apple-pie/slice';

<fieldset>
  <legend>Billing</legend>
  <RadioButton label="Monthly" name="billing" value="monthly" defaultChecked />
  <RadioButton label="Annual" name="billing" value="annual" />
</fieldset>
```
</RenderSource>

## Behavior

Inside RadioButtonList, the group owns selection, shared name, and group-disabled
state. Each choice needs a unique non-null value; explicit child styles override
group defaults. Use the group value/defaultValue rather than child checked props.

Same-name options are exclusive; activating a checked radio leaves it checked.
Use checked/onChange for controlled selection or defaultChecked for local state.
label takes priority over children. Use align=top and textTopOffset for multiline
content. A typed value is returned in callback metadata; formValue supplies its
serialized representation when needed. String/number values are submitted directly.
Uncontrolled controls support native form reset. Controlled state needs application
reset handling. Use CheckBox for independently toggled choices.

## Accessibility

The visible label names and activates a native radio. actionName supplies an alternate
description, with Option as the unnamed fallback. Icons are decorative. Group choices
under a fieldset/legend or an appropriately named group and give them the same name.
Tab enters the group, Space selects, and arrow keys select enabled siblings. Enter
retains native form behavior. Focus is visible, disabled choices are skipped, and
required participates in native validation. Reduced motion disables color transitions.

## Props

All props are optional; colors accept theme tokens or CSS colors.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `actionName` | `string` | `undefined` | Optional action description in place of the visible content. |
| `align` | `'top' \| 'middle' \| 'bottom'` | `middle` | Aligns the icon with the content. Use top for a multiline label. |
| `backgroundColor` | `ColorValue` | `transparent` | Unselected background. |
| `backgroundColorSelected` | `ColorValue` | `transparent` | Checked background. |
| `borderColor` | `ColorValue` | `core-outline-primary` | Border color. |
| `borderRadius` | `number \| string` | `8` | Corner radius; numbers are pixels. |
| `borderWidth` | `number` | `0` | Border width in pixels. Negative or nonfinite numbers become zero. |
| `checked` | `boolean` | `undefined` | Controlled selection. Update this from onChange; activation does not mutate the supplied value. |
| `children` | `React.ReactNode` | `undefined` | Content used when label is absent. Keep nested content noninteractive. |
| `defaultChecked` | `boolean` | `false` | Initial selection for an uncontrolled radio. Use checked for external control. |
| `disabled` | `boolean` | `false` | Blocks interaction and dims the whole control. |
| `fieldName` | `string` | `undefined` | Option identifier included in callback metadata. Native name instead identifies the radio group and form field. |
| `formValue` | `string \| number` | `undefined` | Explicit form submission value. Falls back to value when value is a string or number; otherwise the native value is on. |
| `gap` | `number` | `6` | Pixel gap between icon and content. Zero is supported; negative values become zero and nonfinite values fall back to 6px. |
| `iconChecked` | `string` | `check circle` | Icon while checked. |
| `iconColor` | `ColorValue` | `core-text-primary` | Unselected icon color. |
| `iconColorSelected` | `ColorValue` | `undefined (iconColor)` | Checked icon color. Falls back to iconColor. |
| `iconSize` | `number` | `20` | Icon size in pixels. Zero removes the icon and its gap. Negative or nonfinite values fall back to 20px. |
| `iconUnChecked` | `string` | `circle` | Icon while unchecked. |
| `label` | `string` | `undefined` | Visible text. Takes priority over children. |
| `padding` | `number \| string` | `0` | Uniform surface padding. Numbers are pixels; strings accept CSS shorthand. |
| `textColor` | `ColorValue` | `core-text-primary` | Content color. |
| `textSize` | `'xs' \| 's' \| 'm' \| 'l' \| 'xl'` | `m` | Content size. |
| `textTopOffset` | `number` | `0` | Manual content alignment in pixels. Positive values add top padding; negative values add bottom padding to raise the text. Does not move the icon. |
| `value` | `T` | `undefined` | Typed callback metadata, with T defaulting to string. String and number values also supply the native form value unless formValue is provided. |
| `...inputAttributes` | `React.InputHTMLAttributes<HTMLInputElement>` | `undefined` | Native input attributes such as name, id, form, required, tabIndex, and data attributes apply to the radio input. name groups choices and identifies the submitted field. className and style apply to the outer label; component CSS variables take priority. The input type is always radio. |

## Events

- **onChange**: `(option: RadioButtonOption<T>, checked: boolean) => void`. Runs when this option becomes checked. The option contains fieldName, label, and value. Selecting another option does not emit false for the previously checked input; controlled groups should update all checked props together.
- **onClick**: `React.MouseEventHandler<HTMLInputElement>`. Native input click, including label-forwarded clicks. Calling event.preventDefault() cancels selection and the component change callback.
- **...inputEvents**: `React.DOMAttributes<HTMLInputElement>`. Other native input handlers pass through. Keyboard and form behavior remain native; there are no drag or animation lifecycle callbacks.
