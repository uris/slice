# Button

Labels, icons, and busy states for actions. The default is an m-size outline button with type="button".

## Usage

</Unstyled>
<RenderSource>
```

<Button label="Continue" onClick={continueToNextStep} />
```
</RenderSource>

## Behavior

- Children override label and form a vertically centered flex row using gap. Use buttonSize="auto" for natural height with 6px vertical padding. Decorative icons do not add tab stops.
- Use working for an application-controlled busy state. It blocks repeated activation and does not emit a completion click.
- progress with a positive finite duration delays onClick and supplies undefined when it completes. It does not submit forms or follow links on completion.
- disabled, state="disabled", and busy state block pointer, keyboard, ref, and trigger activation.
- trigger activates once when becoming true. Reset it to false before requesting another activation.
- link uses window.open after an ordinary onClick unless the event is prevented. The element remains a button.

## Accessibility

Native Enter/Space behavior and a focus ring are provided. Give icon-only actions an aria-label. Busy state sets aria-busy; the label remains accessible. Provide application feedback for success and errors.

## Props

ColorValue accepts Slice color tokens and CSS colors. Native button attributes are supported; Motion-owned event names use Motion callback signatures.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `animate` | `string` | `undefined` | Named Motion variant to animate toward. Define the values in variants. |
| `backgroundColor` | `ColorValue` | `variant background` | Background color in normal and hover states. Overrides the preset for every variant; fill takes priority while enabled. |
| `backgroundColorDisabled` | `ColorValue` | `variant disabled background` | Background color when disabled. Independent of backgroundColor. |
| `borderColor` | `ColorValue` | `undefined` | Overrides the variant border color for every size and state, including hover and disabled. Omitted values keep variant defaults. |
| `borderRadius` | `number \| string` | `corner-round` | Corner radius. Numbers use pixels; strings accept CSS lengths. |
| `borderWidth` | `number \| string` | `undefined` | Overrides the variant border width for every size and state. Numbers use pixels; CSS lengths are preserved. Zero removes the border. Omitted values keep variant defaults. |
| `buttonSize` | `'auto' \| 's' \| 'm' \| 'l' \| 'xl' \| number` | `m` | Shared frame heights: 24, 36, 44, 56px. Auto fits content plus padding; a positive number sets a pixel height. |
| `children` | `React.ReactNode` | `undefined` | Custom label content. Takes priority over label; use non-interactive content inside the button. |
| `count` | `number` | `undefined` | Optional count badge. Zero and invalid numbers are hidden; numbers above 99 show 99+. Hidden while busy. |
| `destructive` | `boolean` | `false` | Uses the warning color preset for destructive actions. Explicit color overrides still apply. |
| `disabled` | `boolean` | `false` | Native disabled state. Blocks pointer, keyboard, ref, and trigger activation. Also cancels a pending timed action. |
| `duration` | `number` | `undefined` | Timed progress delay in seconds. Requires progress and a positive, finite value. Has no effect on controlled working state. |
| `exit` | `string` | `undefined` | Named Motion variant for exit animation. Requires an AnimatePresence parent to animate removal. |
| `fill` | `boolean` | `false` | Uses core-surface-primary for the enabled background, ahead of variant and backgroundColor. This controls the fill color, not width. |
| `gap` | `number` | `4` | Pixel gap between icons and content, and between children. Use 0 to remove it. |
| `iconColor` | `ColorValue` | `variant icon color` | Color of both icons. Overrides the preset in all states. |
| `iconFill` | `boolean` | `false` | Fills icon shapes that support a filled appearance. |
| `iconLeft` | `string` | `undefined` | Registered icon name displayed before the label. |
| `iconRight` | `string` | `undefined` | Registered icon name displayed after the label. |
| `iconSize` | `number` | `20` | Icon and spinner size in pixels. |
| `initial` | `string` | `undefined` | Named Motion variant used for the initial appearance. |
| `label` | `string` | `undefined` | Visible action label when children is not supplied. |
| `link` | `string` | `undefined` | URL opened after a normal activation with window.open. onClick can cancel navigation with event.preventDefault(). Timed progress does not navigate on completion. |
| `padding` | `number \| string` | `automatic` | Shorthand padding. Children and auto sizing use 6px vertically. Shared horizontal padding is 12px with a 4px reduction on icon edges; text buttons use 4px. Explicit padding disables optical adjustment. |
| `paddingBottom` | `number \| string` | `automatic` | Bottom padding; overrides padding. |
| `paddingLeft` | `number \| string` | `automatic` | Left padding overrides padding and shared optical defaults. Numbers are pixels. |
| `paddingRight` | `number \| string` | `automatic` | Right padding overrides padding and shared optical defaults. Numbers are pixels. |
| `paddingTop` | `number \| string` | `automatic` | Top padding; overrides padding. |
| `progress` | `boolean` | `false` | Enables delayed activation when duration is positive and finite. The spinner runs first, then onClick receives undefined once. Without a valid duration, activation is immediate. |
| `round` | `boolean` | `false` | Makes the default-width button circular. Intended for icon-only actions with an accessible label. |
| `showDot` | `boolean` | `false` | Shows a status dot. Hidden while busy. |
| `state` | `'normal' \| 'hover' \| 'disabled'` | `normal` | Forces the hover or disabled presentation. Use disabled for ordinary application disabling; either disabled mechanism blocks activation. |
| `target` | `'_blank' \| '_self' \| '_parent' \| '_top'` | `_self` | Window target used with link. |
| `textColor` | `ColorValue` | `variant text color` | Text color in normal and hover states. Disabled text retains the disabled preset. |
| `textSize` | `'xs' \| 's' \| 'm' \| 'l' \| 'xl'` | `m` | Theme typography size for the label or children. |
| `tooltip` | `string` | `undefined` | Label sent to onToolTip on hover or focus. The component does not display a tooltip by itself. |
| `transition` | `Transition` | `undefined` | Motion transition options. Duration here is measured in seconds and controls animation, independently of the progress delay. |
| `trigger` | `boolean` | `false` | Requests one activation when it becomes true, including an initially true value. Reset to false before triggering again. Requests made while disabled or busy are ignored, not queued. |
| `type` | `'button' \| 'submit' \| 'reset'` | `button` | Native form behavior. Use submit or reset inside a form; the default avoids accidental submission. |
| `underline` | `boolean` | `false` | Underlines the label on hover and keyboard focus. |
| `variant` | `'solid' \| 'outline' \| 'text'` | `outline` | Visual preset. Solid emphasizes the action, outline adds a border, and text uses a transparent background unless overridden. |
| `variants` | `Variants` | `undefined` | Named Motion animation definitions used by initial, animate, and exit. |
| `width` | `string` | `min-content` | CSS width, or fill to take the available parent width. Min-content sizes to the content; the label truncates when constrained. |
| `working` | `boolean` | `false` | Controlled busy state. Shows a spinner and blocks repeated activation until false. Changing this prop does not call onClick or determine whether an operation succeeded. |
| `buttonAttributes` | `React.ButtonHTMLAttributes<HTMLButtonElement>` | `undefined` | Other native attributes pass through, including form, name, value, title, data-* and aria-*. className is appended and style is merged; component styles take priority for the properties they manage. Disabled and busy attributes remain consistent with the component state. |

## Events

| Event | Type | Description |
| --- | --- | --- |
| `onAnimationStart` | `HTMLMotionProps<'button'>['onAnimationStart']` | Motion animation-start callback. Receives an animation definition, not a native AnimationEvent. |
| `onClick` | `(event: React.MouseEvent<HTMLButtonElement> \| undefined) => void` | Receives the click event for normal pointer or keyboard activation. Receives undefined for ref/trigger activation and after timed progress. Controlled working does not emit a completion click. |
| `onToolTip` | `(tip: ToolTip \| null) => void` | Receives type, payload.label, and the button ref on hover or focus. Hover also includes the pointer event. Null clears the tooltip after hover and focus end, or on activation. |
| `buttonEvents` | `React.DOMAttributes<HTMLButtonElement>` | Other native handlers pass through. onMouseEnter, onMouseLeave, onFocus, and onBlur run alongside internal hover and tooltip behavior. The animation callback above uses Motion’s signature. |

## Ref

The forwarded ref is a ButtonHandle, not a DOM element. Its triggerClick() method requests activation with an undefined event and honors disabled/busy state. It does not focus the element or submit/reset a form.
