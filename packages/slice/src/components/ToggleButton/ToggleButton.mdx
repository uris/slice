# ToggleButton

Make on/off actions clear with a label, an optional icon, and a selected state.

## Usage

</Unstyled>
<RenderSource>
```
import { ToggleButton } from '@apple-pie/slice';

<ToggleButton icon="weather.sun" label="Highlight" />
```
</RenderSource>
<Unstyled>

### Control selection

Use selected/onChange for controlled state, or defaultSelected for local state.
Set deselect=false to keep an active selection.

</Unstyled>
<RenderSource>
```
<ToggleButton label="Highlight" selected={selected} onChange={setSelected} />
```
</RenderSource>
<Unstyled>

### Animate an icon on toggle

Give selected and unselected different animation targets, such as rotation or scale.

</Unstyled>
<RenderSource>
```
<ToggleButton
  icon="weather.sun"
  label="Highlight"
  motionValues={{ unselected: { rotate: 0 }, selected: { rotate: 135 } }}
  transition={{ duration: 0.2 }}
/>
```
</RenderSource>

## Behavior

Icon and text are one button. label takes priority over children. onClick runs first;
preventDefault cancels selection. Selected colors win over hover colors. Default
padding compensates for internal icon space on the left, or both sides for an
icon-only toggle. Explicit padding is authoritative.

## Accessibility

Enter and Space activate the native button; keyboard focus is visible and aria-pressed
exposes selection. Disabled blocks both icon and label and removes the Tab stop.
The visible string label or numeric content names the action. Use actionName for
rich or icon-only content; missing or blank names fall back to “Action”. Direct
aria-label/aria-labelledby props are not exposed. Icons are decorative and not tabbable.
Reduced motion disables icon and color animation, including custom delays/repeats,
while preserving keyboard focus on live preference changes.

## Motion

transition settings are merged with Slice’s Water transition. One transition drives
icon animation and background, icon, and text colors.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `motionValues` | `Variants` | `undefined` | Inner-icon animation targets named selected and unselected, merged with neutral rotate=0, scale=1, and opacity=1 values. Variant functions receive the selection boolean. Per-variant transition settings are ignored; use transition. |
| `transition` | `Transition` | `undefined` | Shared timing for icon animation and background, icon, and text colors. Partial settings are merged with Slice’s Water transition. |

## Events

- **onChange**: `(selected: boolean) => void`. Requests the next selection after an uncancelled activation. Does not run when deselect=false keeps an active selection.
- **onClick**: `React.MouseEventHandler<HTMLButtonElement>`. Runs before selection handling. Calling event.preventDefault() cancels the change. Disabled buttons do not activate.
- **onToolTip**: `(tip: ToolTip | null) => void`. Requests a tooltip on hover or focus. ToolTip carries type, payload.label, and the button ref; event is present for mouse requests and absent for focus. Sends null on activation, when both hover and focus end, on disable, tooltip changes or callback removal, or unmount.
- **...buttonEvents**: `React.DOMAttributes<HTMLButtonElement>`. Other native button handlers are composed with internal behavior. Preventing default on mouse entry or focus suppresses that internal handling. No drag or pan gestures are implemented.
