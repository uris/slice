# Slider

Choose continuous values with a custom track and head over a native range input.

## Usage

```
import { Slider } from '@apple-pie/slice';

<Slider aria-label="Volume" />
```

Use controlled `value` with `onChange`, or `defaultValue` for an initial uncontrolled value. `min` and `max` bound the value. `step` controls keyboard increments only: dragging remains continuous, and keyboard changes start from the current value without snapping to a grid. Arrow and Page keys move by one increment; Home/End select the bounds.

`onChange(value, percent)` reports live changes, with percent in the range 0–1. `onChangeEnd(value, percent)` reports a changed interaction after pointer release or key release, including repeated keys. Blur commits pending keyboard changes; canceled, disabled, or unmounted interactions do not commit. Atomic assistive-technology changes commit immediately. External prop updates and unchanged values emit no callbacks.

## Accessibility

Name the input with `aria-label`, `aria-labelledby`, or an associated HTML label. Native attributes and events target the input; className/style apply to the wrapper. Keyboard focus has a visible inset indicator. Disabled inputs are not focusable and are excluded from form submission. Pass name to submit the current value.

A nonzero head can fade in on hover, keyboard focus, or dragging with `trackHeadOnHover`. Water timing respects reduced motion, including live preference changes. Value movement follows input directly.

## Events

`onChange(value, percent)` and `onChangeEnd(value, percent)` are numeric component callbacks. Native input events pass through as a group. `onKeyDown` and `onPointerDown` run first; preventDefault cancels the corresponding interaction. This component does not expose Motion gestures.
