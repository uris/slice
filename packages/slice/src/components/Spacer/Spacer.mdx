# Spacer

Reserve a fixed square of empty space using the theme spacing grid.

## Behavior

The default square is 8px on each side. It does not shrink in flex layouts, and its dimensions take priority over conflicting style values. Use a parent’s gap for regular spacing between repeated items.

## Accessibility

Spacer has no status or interactive semantics. Keep it empty and avoid adding focus or click behavior.

## Props

- `size` (`'xxs' | 'xs' | 's' | 'm' | 'l' | 'xl' | 'xxl' | 'h'`, default `s`): Spacing token for both dimensions: 2, 4, 8, 16, 24, 32, 64, or 128px by default. Custom theme spacing tokens are respected.

Native div attributes apply to the root. Component dimensions take priority over style.

## Events


Native div event handlers apply to the root.
