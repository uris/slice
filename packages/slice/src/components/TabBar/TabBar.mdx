# TabBar

Compose related views with shared value-based selection and a sliding, resizing underline.

TabBar manages a group of [Tab](?path=/docs/components-tab--docs) choices.

## Usage

```
import { Tab, TabBar } from '@apple-pie/slice';

<TabBar tabBarName="Project views" defaultValue="overview">
  <Tab value="overview" label="Overview" />
  <Tab value="activity" label="Activity" />
</TabBar>
```

### Use options

```
<TabBar tabBarName="Project views" options={[
  { value: 'overview', label: 'Overview' },
  { value: 'activity', label: 'Activity', count: 12 },
]} />
```

### Control selection

```
<TabBar tabBarName="Project views" value={activeView} onChange={setActiveView} options={options} />
```

## Behavior

Children take priority over options. Values must be unique and non-null; prefer stable strings or numbers. Object values are matched by reference. Selection survives reordering. Omit defaultValue to select the first enabled tab, or use null for no initial selection. An unmatched or removed value leaves no selected tab. Your application renders panels and handles closing.

## Accessibility

Use tabBarName to name the tablist. The component supplies its ARIA label, with Tabs as the fallback; blank names also use Tabs. ARIA attributes are managed internally. Left/Right arrows wrap through enabled tabs; Home/End select the first/last enabled tab. Tab enters the selected enabled choice, or the first enabled choice when none matches. Native disabled tabs and the close action block interaction. Icons and the indicator are decorative; the close action sits outside the tablist. Use each tab’s id and panelId to connect application-rendered tabpanels. Reduced motion disables underline movement and color transitions, including live preference changes.

## Motion

`transition` is merged with Slice’s water transition and controls the shared underline’s position and width. Container and tab size changes update its destination.

```
<TabBar tabBarName="Project views" options={options} transition={{ duration: 0 }} />
```

Set duration to 0 to snap into place. Reduced motion takes priority over custom timing.

## Events

- `onChange(value, option)` requests a different selection. Repeat activation, initialization, and prop changes do not emit it.
- `onClose()` handles the whole-bar close action.
- `onToolTip(tip)` provides tooltip data on hover; null clears it on leave or selection. Your application renders the tooltip.
- Native div events apply to the tablist. Composed tabs accept native button handlers, which run first; preventDefault cancels internal click or keyboard handling.
