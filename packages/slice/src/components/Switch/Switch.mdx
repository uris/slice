        # Switch
        Renders a binary on/off control for toggling settings and preferences.

        ## Base element
        `HTMLButtonElement`

        ## Interface
        `SwitchProps<T = string>`

        ## Typing
        `Switch` is generic. The `value` prop uses the same `T` that comes back through `onChange`.

        `onChange` receives:

        `(value: T | undefined, checked: boolean) => void`

        ## Notes
        - `Switch<string>` is the default if you do not provide a generic.
        - Use `Switch<T>` when the switch should carry a typed value object or non-string identifier.
        - `checked` controls the on/off state; omit it to use local state, optionally initialized with `defaultChecked`. `value` is callback metadata, not a submitted form value.
        - Native `onClick` runs before toggling; call `event.preventDefault()` to cancel the change.
        - Invalid dimensions fall back to 48 × 22px; width is at least height and padding is clamped to retain a knob of at least 1px.

        ## Accessibility
        Use `name` to name the setting. Its trimmed value supplies `aria-label`; omitted or blank values use `Switch`. The native button has `role="switch"`, reports `aria-checked`, supports Enter/Space, and provides an inset keyboard focus indicator.

        Reduced-motion preferences disable knob animations and track transitions, including custom delays. Live changes preserve focus.

        ## Events
        `onChange(value, checked)` reports user changes. Native button events pass through; Motion gestures are not part of the public API.

        Set `knobWidth` for a pill-shaped knob. Use `knobRadius` for knob corners and `borderRadius` for track corners. Defaults preserve the rounded appearance.
