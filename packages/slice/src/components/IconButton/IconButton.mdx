### Animate an icon on toggle

Give selected and unselected different animation targets, such as rotation or scale.
The icon animates between them when toggled. This example uses rotation.

</Unstyled>
<RenderSource>
```
<IconButton
  icon="weather.sun"
  actionName="Highlight"
  toggle
  motionValues={{ unselected: { rotate: 0 }, selected: { rotate: 135 } }}
/>
```
</RenderSource>

## Behavior

Use toggle with selected/onChange for controlled selection, or defaultSelected for
local state. onClick runs first; preventDefault cancels selection. Selected colors
win over hover. buttonSize accepts a preset or positive finite pixels.

## Accessibility

actionName supplies the internal aria-label, falling back to “Action” for missing,
empty, or whitespace-only names. Set a specific action name. Direct aria-label and
aria-labelledby props are not exposed. Enter and Space activate the native button;
keyboard focus is visible. Toggles expose aria-pressed. Icons, dots, and counts are
decorative; describe meaningful status in the action name or nearby text.
Disabled buttons cannot be activated or reached with Tab. Reduced motion disables
color and icon animation, including custom delays/repeats, without losing focus.

## Motion

motionValues configures selected/unselected icon variants. transition drives both
color and icon animation, merged with Slice’s Water transition.

## Events

- **onChange**: `(selected: boolean) => void`. Requests the next toggle state after an uncancelled activation. Runs only when toggle=true.
- **onClick**: `React.MouseEventHandler<HTMLButtonElement>`. Runs first for pointer or keyboard activation. Calling event.preventDefault() cancels selection changes and onChange. Disabled buttons do not activate.
- **onToolTip**: `(tip: ToolTip | null) => void`. Requests tooltip content on hover or focus. ToolTip carries type, payload.label, and the button ref; event is present for mouse requests and absent for focus. Sends null on activation, when both hover and focus end, when disabled, when tooltip text changes, or on unmount.
- **...buttonEvents**: `React.DOMAttributes<HTMLButtonElement>`. Native handlers are composed with internal hover and focus handling. Preventing default on entry or focus suppresses the corresponding internal behavior. There are no drag or pan gestures.
