# Pager

Navigate pages with compact dots, distance scaling, and a masked sliding window.

## Usage

```
import { Pager } from '@apple-pie/slice';

<Pager pages={20} maxVisiblePages={5} showMoreOn={4} />
```

Use controlled `selectedIndex` with `onChange`, or `defaultSelectedIndex` for the initial uncontrolled page. Indices start at zero. Re-selecting the current page does not emit a change.

Each dot uses `max(minScale, scale * scaleFactor ** distance)`; `scaleFactor={1}` keeps all dots equally sized. `showMoreOn` is a one-based visible-dot position, mirrored when moving backward. With five visible dots, it defaults to dot 4 forward and dot 2 backward. Each triggered shift reveals enough pages to center the selection, limited by the available pages at either end. Even-sized windows use the right of the two middle positions. Sliding is enabled for at least five total pages.

## Accessibility

The outer div is a named group; use `aria-label` to describe it. Native page buttons have labels, ordinary tab order, visible keyboard focus, and `aria-current="page"` on the selection. Enter and Space activate once. Outgoing dots are inert and hidden from assistive technology. Reduced motion disables Water sliding, scaling, and color transitions, including live preference changes.

## Motion

`transition` accepts Motion's `Transition` settings, merged with Slice’s Water transition. One prop controls sliding, scaling, opacity, and color changes. Reduced motion makes all changes immediate.

```
<Pager pages={20} maxVisiblePages={5} transition={{ duration: 0.4 }} />
```

## Events

`onChange(index)` runs once for a different user-selected page. Controlled prop changes do not emit it. Native div events pass through as a group; Motion gestures are not part of this API.
