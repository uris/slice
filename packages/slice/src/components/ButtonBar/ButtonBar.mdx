# ButtonBar

Group icon actions with circular hover and selection highlights. The bar uses a
native button group; `tip` provides each accessible name. Icons are decorative.

## Usage and behavior

Enable `toggle`, then use `defaultSelectedIndex` for local selection or `selectedIndex` plus `onChange` for controlled
selection. Indices are zero-based. Set `selectedIndex={null}` to clear a controlled
selection. Invalid indices display no selection. Defaults are read once;
controlled selection changes only when the parent updates `selectedIndex`.

Buttons are independent actions by default. Enable `toggle` for selection: buttons expose `aria-pressed`. Activating a different item calls
`onClick`, then `onChange`. With `toggle={false}`, items are independent actions without
pressed state or change notifications. Items render no labels.

`buttonSize` presets match Button’s overall height: s=24px, m=36px, l=44px, and xl=56px. The inner circles subtract the default 4px inset on each side and the outer border. Positive numeric sizes instead specify the inner circle diameter. `iconSize` controls its icon. The bar
uses padding (4px by default) uniformly inside its wrapper, and buttonGap (-2px by default) between buttons. Set padding to 0 for no inset. Negative
buttonGap values overlap buttons and their hit areas. selectionRadius shapes each
hover/selection highlight and its inset focus indicator; the default is 50% (a circle). `backgroundColor` colors the bar; hover and
selected colors apply to the individual circles. `borderRadius` affects only the
outer bar, and `borderWidth` adds an outer border without internal separators.

## Accessibility

The root is a group named “Actions”; override its `aria-label` for context. Each
button uses `tip` as its name. Enter and Space activate a button, Tab visits each
button, and focus-visible shows an inset indicator. This is not a tab list or radio group.
Tooltips can be requested on focus as well as hover; the application renders them.
Color changes use the theme’s Water duration and easing, with transitions disabled
when the viewer prefers reduced motion.

## Events

<tr>
<td>
<code>onChange</code>
</td>
<td>
<code>(button: BarButton) =&gt; void</code>
</td>
<td>Requests a different selection when toggle is true. Receives the original record, not its index. Suppressed when the selected item is activated again. Programmatic prop changes do not emit this callback.</td>
</tr>
<tr>
<td>
<code>onClick</code>
</td>
<td>
<code>(button: BarButton) =&gt; void</code>
</td>
<td>Runs for every pointer or keyboard activation, including the already selected item. Runs before onChange when both are emitted.</td>
</tr>
<tr>
<td>
<code>onToolTip</code>
</td>
<td>
<code>(tip: ToolTip &#124; null) =&gt; void</code>
</td>
<td>Receives text and the button ref on hover or focus; a mouse event is included for hover only. Receives null on activation or after both hover and focus have left. Your application renders the tooltip.</td>
</tr>
</tbody>
</table>

Other native events apply to the group root. `onClick` and `onChange` above use
component item payloads rather than native event objects.
