# DraggablePanel

Build a split workspace with a resizable sidebar. Mouse, touch, pen, and keyboard resizing share the same constraints and callbacks.

```tsx
import { Button, DraggablePanel } from '@apple-pie/slice';
import { useRef, useState } from 'react';

export function Workspace() {
  const containerRef = useRef<HTMLDivElement>(null);
  const [closed, setClosed] = useState(false);
  return <div ref={containerRef} style={{display: 'flex', height: 320}}>
    <DraggablePanel containerRef={containerRef} isClosed={closed}
      sizeConstraints={{initial: 240, min: 160, max: 0.6}}
      resizeHandleLabel="Resize project sidebar">
      Project navigation
    </DraggablePanel>
    <main style={{flex: 1, minWidth: 0, padding: 24}}>
      <Button label={closed ? 'Open sidebar' : 'Close sidebar'} onClick={() => setClosed(!closed)} />
      Workspace content
    </main>
  </div>;
}
```

## Behavior and accessibility

The panel starts closed by default. Fixed widths render on the server; relative initial widths settle once the container is measured. Reopening restores the previous resized width within the current constraints. Closed content remains mounted, inert, and hidden from assistive technology.

Use `drags="right"` for a sidebar on the left and `drags="left"` for a sidebar on the right. `drags={false}` fills available width without a resize rail; `isClosed` still collapses the panel. Give the layout a height and a flexible sibling with `minWidth: 0`.

The rail is a named vertical separator exposing current width and bounds. Left/Right arrows move the edge by 10px; Shift increases the step to 50px. Home/End choose the minimum/maximum. Escape ends an active pointer resize. Focus outlines appear for keyboard focus; reduced motion disables width/highlight transitions.

Pointer movement changes width without a React render on every move. Cancellation, blur, and unmount release pointer capture and listeners and restore the document's prior selection styles. Use `onResizeEnd` for expensive work that only needs the final size.

### Keep content stable while closing

For a pixel minimum, set the inner content wrapper's `minWidth` to the same value as `sizeConstraints.min`. This prevents squeezing and rewrapping during the closing animation. Keep that minimum on the inner wrapper so the panel itself can still collapse to zero and clip its content. Percentage minimums need a resolved pixel width for this pattern.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `backgroundColor` | `ColorValue` | `transparent` | Panel background. |
| `borderLeft` | `CSSProperties['borderLeft'] \| null` | `1px solid var(--core-outline-secondary)` | Border on the left resize edge while open. Null removes it. |
| `borderRight` | `CSSProperties['borderRight'] \| null` | `1px solid var(--core-outline-secondary)` | Border on the right resize edge while open. Null removes it. |
| `children` | `ReactNode` | — | Panel content. |
| `containerRef` | `RefObject<HTMLDivElement \| null>` | — | Container width for relative constraints; otherwise uses viewport width. |
| `disableOnContext` | `boolean` | `false` | Prevents the context menu after calling `onContextMenu`. |
| `dragHandle` | `boolean` | `true` | Shows the visual grip; the resize rail remains available when hidden. |
| `dragHandleStyle` | `DragHandleProps` | `{height: 24, width: 9}` | Grip `width`, `height`, `radius`, `stroke`, `strokeColor`, and `color`. |
| `drags` | `'left' \| 'right' \| false` | `'right'` | Resize edge, or false to fill available width without resizing. |
| `isClosed` | `boolean` | `true` | Controlled collapsed state. |
| `isTouchDevice` | `boolean` | `false` | Expands the rail to 44px and removes highlight delay; touch also works without this option. |
| `resizeHandle` | `ResizeHandle` | `{width: 10, color: 'transparent', offsetX: true}` | Rail width/color. `offsetX` is retained for compatibility and has no effect; the rail stays centered on the edge. |
| `resizeHandleLabel` | `string` | `Resize panel` | Accessible rail name. Use distinct labels for multiple panels. |
| `sizeConstraints` | `Constraint` | `{initial: 250, min: 250, max: 500}` | Values 0–1 are container ratios; larger values are pixels with a 50px floor. Invalid values use defaults; bounds and initial width are normalized. |
| `transitionDurationOnInit` | `number \| string` | — | Initial relative-size transition only. Numbers are milliseconds; strings are CSS durations. Later transitions use Water timing. |
| `...divAttributes` | `HTMLAttributes<HTMLDivElement>` | — | Native wrapper attributes, classes, styles, and events. The panel owns width/layout. |

## Events

`onResizeStart`, `onResize`, and `onResizeEnd` receive the exported `DraggablePanelResizeInfo`:

```ts
type DraggablePanelResizeInfo = {
  div: React.RefObject<HTMLDivElement | null>;
  divWidth: number;
  divHeight: number;
  deltaWidth: number;
};
```

`onResize` runs at start, for accepted changes, and at end. `onResizeStart` and `onResizeEnd` bracket each gesture or keyboard resize. For compatibility, `deltaWidth` remains pointer movement from the gesture start, so left-edge growth is negative; start/end notifications use zero. Cancellation while mounted ends the gesture; unmount only cleans up.
