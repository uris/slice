# DoneCheck

Show a completion checkmark with an optional scale animation.

## Behavior

The check animates on mount by default, with no delay. Setting play to false shows the completed check immediately; it does not hide or pause it. Changing play from false to true replays the entrance. Timing values are in seconds.

## Accessibility

The root is a polite status named by statusLabel, falling back to “Completed” for an empty label. Set decorative when nearby text already conveys completion. The inner icon is hidden from assistive technology. Reduced motion shows the check immediately, ignoring animation delay. Applications should announce changing operation results in their own live text; the visual animation alone does not guarantee an announcement.

## Props

- `color` (`ColorValue`, default `feedback-positive`): Checkmark color, accepting a Slice theme token or CSS color.
- `decorative` (`boolean`, default `false`): Hides the entire check from assistive technology.
- `delay` (`number`, default `0`): Delay before the entrance, in seconds.
- `duration` (`number`, default `1`): Entrance duration in seconds. Zero or negative values show the check immediately.
- `play` (`boolean`, default `true`): Enables the entrance animation.
- `size` (`number`, default `88`): Reserved square dimensions in pixels.
- `statusLabel` (`string`, default `Completed`): Accessible status name.
- `stroke` (`number`, default `1.5`): Stroke width in the icon’s 20-unit SVG coordinate system.

Native div attributes apply to the root. Component dimensions take priority over style.

## Events

- `didEnd: () => void`: Runs when the scale transition finishes. It does not run for skipped or cancelled transitions.
- `didStart: () => void`: Runs when the scale transition starts, after its delay. It does not run when animation is skipped.

Native div event handlers apply to the root.
