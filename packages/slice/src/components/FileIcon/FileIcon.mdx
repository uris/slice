# FileIcon

Themed file artwork. Pass `filename` as a string or File; its extension (or `File.name`) selects the category, case-insensitively. MIME type is ignored. An explicit `type` overrides inference. Missing or unknown types use `other`.

```tsx
import { Button, FileIcon } from '@apple-pie/slice';

export function FileAction() {
  return <Button variant="outline" onClick={() => console.log('open')}>
    <FileIcon filename="report.PDF" size={32} decorative />
    <span>Open report.pdf</span>
  </Button>;
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| decorative | boolean | false | Hides a passive icon from accessibility APIs. |
| disabled | boolean | false | Dims the icon, blocks activation, and removes interactive icons from the tab order. |
| filename | string or File | undefined | Infers artwork from the filename extension; never MIME type. |
| label | string | category description | Accessible image or action name; takes precedence over aria-label. |
| pointer | boolean | onClick provided | Cursor preference only; does not disable keyboard activation. |
| size | number | 24 | Width and height in pixels; invalid sizes fall back to 24. |
| type | FileIconType | inferred or other | Explicit category override. |
| ...svgAttributes | SVGAttributes | — | Native attributes, styles, class names, and events. Interaction semantics are managed internally. |

`FileIconTypes` lists pdf, text, sheet, preso, md, code, image, audio, video, and other. `resolveFileIconType(filename)` exports the same resolution for use independently; its result can be passed directly to `type`.

## Interaction and accessibility

Passive icons have an image role. Use `decorative` beside equivalent text. Supplying `onClick` makes the SVG a keyboard-accessible action even when `pointer={false}`; provide a task-specific label. Actions always remain accessible, including when `decorative` is supplied. Keyboard focus uses `:focus-visible`.

Enter activates on keydown and Space on release; blur cancels pending Space activation. `onClick` receives a `React.MouseEvent<SVGSVGElement>` for both pointer and keyboard activation (keyboard clicks have `detail: 0`). Native key handlers run first and may call `preventDefault()` to cancel internal activation. A forwarded ref targets the SVGSVGElement.
