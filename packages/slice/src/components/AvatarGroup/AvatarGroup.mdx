        # AvatarGroup
        Renders a stacked list of avatars for participants, assignees, or collaborators.

        ## Base element
        `HTMLDivElement`

        ## Interface
        `React.HTMLAttributes<HTMLDivElement> & AvatarGroupProps`

        Pass individual `<Avatar>` children or an `avatars` array. When `children !== undefined`, children replace the array, including `null` and empty children. Group appearance props provide defaults; explicitly defined child props override them. Fragments and components that render avatars inherit the same defaults.

        Child native events bubble to the container normally. A child handler runs before the container's bubbling handler and can call `event.stopPropagation()`. Each child's handlers retain its own `info`. A child's `onToolTip` overrides the group's default callback.

        Set `limit={5}` to show at most five people followed by a matching `+N` avatar for the remaining people. The overflow avatar is additional to the limit. Omit `limit` to show everyone. Zero shows only the overflow avatar; finite limits are floored and clamped to zero, and non-finite limits mean unlimited.

        Children are counted after flattening arrays and fragments and removing empty nodes. Supply one avatar per child slot; avatars rendered inside a custom component cannot be counted individually.

        `onMore({ more, all, source })` runs on click or keyboard activation of the overflow avatar. The lists preserve order and exclude the generated overflow avatar. For `source: 'avatars'`, they contain the original records; for `source: 'children'`, they contain flattened React nodes with their props and handlers intact. Without `onMore`, the overflow avatar is informational.

        Give records unique, stable IDs to preserve avatars when reordering. IDs are not DOM attributes.

import { AvatarGroup } from '@apple-pie/slice';

const avatars = [
    {
        id: 'john',
        first: 'John',
        last: 'Appleseed',
        image: '/images/profile-male-02.jpg',
        email: 'john@email.com',
    },
    {
        id: 'jane',
        first: 'Jane',
        last: 'Appleseed',
        email: 'jane@email.com',
        backgroundColor: 'var(--core-surface-tertiary)',
    },
];

export function TeamAvatars() {
    return (
        <AvatarGroup
            avatars={avatars}
            size={38}
            overlap={8}
            borderWidth={3}
            outerBorderWidth={3}
        />
    );
}
