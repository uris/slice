# Overview board

The `/docs/react/overview/` page is a collection of local, interactive examples.
Each demo block has its own file in `components/`, `hooks/`, `stores/`, or
`utilities/`. Each folder has an overview file that assembles its blocks.
To add a block, create its file and import it into the corresponding section.
For Components, edit the `blocks` list in `components/ComponentsOverview.tsx`
to add or reorder demos.

`OverviewBoard.tsx` owns the tabs and shared menu controller. `Shared.tsx`
contains the common card shell, row layout, people, and toast helper.
`Overview.module.css` owns the responsive column layout.

Forms, chat messages, and uploads use local demo state. The voice demo sends live
audio to OpenAI while connected; it does not record audio or display transcripts. Camera and
microphone access require a click; streams and object URLs are released on unmount.
Video uses the public MDN CC0 flower sample. Dialogs, video overlays, tooltips, and
toasts reuse the website's existing controllers; the board owns its menu controller.

The checkout uses fictional, local-only card details. The project menus use inline PopMenu instances so they stay visible in the overview.

The voice demo proxies the same token service as the portfolio site. Configure
`PRIVATE_API_BASE_URL` on the website server to point to the API that serves
`POST /openai/realtime/session`; the OpenAI API key stays on that API server.
The browser receives only an ephemeral token and connects directly over WebRTC.
The existing backend rate limit still applies. Deployments must set this server
variable; local `.env.local` configuration is ignored by Git.

Run the token-route contract checks with
`node --test apps/website/tests/realtime-session.test.cjs` from the repo root.

Tab badges count the library's public exports, not the rendered demos.
`libraryInventory.json` is generated by `npm run generate:library-inventory`
(in the website workspace), also run before dev/build. Components include public
subcomponents and ThemeProvider. Hooks include the hooks entry point and root
hook exports. Stores count state containers from public store entry points,
excluding selectors and actions. Utilities count exported functions/classes from
the utility and root entry points. Types, enums, and repeated aliases are excluded.
Shipped deprecated exports remain included. Edit `pageTaglines` in
`OverviewBoard.tsx` to replace the placeholder copy beneath the tabs.
